# PetCare - ติดตามสัตว์เลี้ยง

เพิ่มระบบติดตามสัตว์เลี้ยงลงในโปรเจกต์เดิมแล้ว

## วิธีใช้งาน
1. เปิดแอปและเข้าสู่หน้า Home
2. กดเมนู "ติดตามสัตว์เลี้ยง"
3. กรอกชื่อสัตว์เลี้ยง
4. เลือกสถานะ
5. กด "อ่านตำแหน่งปัจจุบัน" และอนุญาต Location
6. กรอกหมายเหตุถ้าต้องการ
7. กด "บันทึก"
8. ประวัติจะถูกเก็บไว้ในเครื่อง
9. กด "เปิดแผนที่" เพื่อดูพิกัดในแอปแผนที่
10. กด "ลบ" เพื่อลบประวัติ

หมายเหตุ: ระบบนี้บันทึกพิกัดล่าสุดจาก GPS ของโทรศัพท์ ไม่ใช่การติดตามปลอกคอสัตว์แบบเรียลไทม์
